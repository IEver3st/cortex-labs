Cortex Studio is a real-time 3D livery previewer and workflow tool for GTA V / FiveM assets.
It’s built for fast iteration: save from your editor → Cortex reloads → inspect the result instantly.

## What you can do

- Preview vehicle liveries, paint, mod kits, lighting, and textures in **Vehicle**, **Multi**, and **Sirens**.
- Dress freemode and custom peds, preview animations, and build addon packs in **EUP Studio** (or inspect individual `.ydd` files in **EUP**).
- Inspect, audit, attach, and export `.ydr`, `.ydd`, `.yft`, `.glb`, and `.gltf` props in **Prop Studio**.
- Stage vehicles, people, and props together in **Photo Mode**, and audition engine/siren audio in **Sound Studio**.
- Generate layered templates in **Template Generator** and manage/export PSD variants in **PSD Variant Builder**.

- Some features require the native desktop runtime (Tauri). If you run only the web UI, file system integrations won’t be available.
