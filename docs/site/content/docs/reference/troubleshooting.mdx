## “File picker does nothing” or “Open model” is disabled

You’re probably running the UI-only server.

- Recommended: run the desktop app:

```bash
bun run tauri dev
```

## Model loads but nothing renders

Try these checks:

- Toggle the grid to confirm the scene is alive.
- Use camera reset/fit.
- Try **All** mode to force texture application everywhere.
- If the model is extremely tiny/huge, check scale/orientation.

## `.yft` fails to load / mentions mesh cache

- Ensure `CodeWalkerBridge.exe` exists in one of the expected locations.
- Confirm the bridge prints JSON metadata to stdout and writes the `.clmesh` file.

See **YFT Parser CLI Contract** for exact requirements.

## Texture reload feels inconsistent

Some editors save via temp-file replacement.

Try:

- Re-selecting the texture path.
- Using PNG as a control test.
- Ensuring the file extension is supported.
- In Multi, a message names any livery that can't be watched; re-select it after saving.

## The model's own textures don't match my `.ytd`

- After saving a `.ytd`, open the model again: replace it with the same file (the folder button on its card), or open it in another tab. Cortex Studio reads the model's texture dictionaries again whenever one of them changed. A model already on screen keeps the textures it loaded with.
- A `.ytd` your resource streams replaces the game's dictionary with the same name, as it does in game. If the vehicle uses a base-game name such as `police3` and you removed or renamed a texture in its `.ytd`, that texture shows as not found rather than the game's version. Parent dictionaries and `vehshare` still come from the game files.

## A `.pdn` texture doesn't load

Cortex Studio flattens a Paint.NET file the way Paint.NET shows it: visible layers with their opacity and blend mode (all 14 of Paint.NET's, such as Multiply, Overlay and Screen), hidden layers left out. When it can't do that, the error says why instead of showing a wrong image.

- A visible layer uses a blend mode Paint.NET doesn't have, which can happen with a damaged file (the error names the layer): set the layer's blend mode to Normal in Paint.NET, or save a flattened PNG copy.
- The file comes from an old Paint.NET version: open it in a current Paint.NET and save it again.
- The file is damaged or was still being written: save it again, then reload.

## Glass/window targeting is wrong

- In Livery mode, auto-targeting is heuristic.
- Use the glass/window selection tools to override.
- If “Exterior Only” is enabled, it may exclude the material you expect.

## Multi mode: gizmo doesn’t appear

- Toggle the Multi gizmo (default hotkey: Alt + G).
- Ensure you’ve selected a slot (A/B) before trying to move it.

## Reset to defaults

If the UI feels “weird” after lots of changes:

- Open Settings and use reset options.
- Restart the app.

Settings are stored locally, so resets are safe and don’t affect your files.
