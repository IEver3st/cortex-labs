---

Open Settings from the top bar (gear icon).

## System

- **UI scale**: scales the interface via a CSS variable (`--es-ui-scale`).
- **Recents**: show/hide recent workspaces on the Home screen.

## Viewer

- **Exterior only default**
- **Window/glass targeting behavior**
- **Free camera**: focus a model preview for scoped WASD flight, right-mouse free-look, Q/E elevation, Alt precision, and Shift boost
- **Render effects**: a global `Ground Shadows` toggle for Studio viewer tabs
- **Grid visibility**
- **Light intensity / glossiness** defaults

## Shortcuts

Customize all key actions (new tabs, file selection, viewer toggles).

## Appearance

- **Color scheme**: follow the operating system or keep the interface in Light or Dark mode.
- **Studio palette**: choose from 12 full-workbench color presets. Palette and color scheme are independent, so every preset supports both light and dark surfaces.
- **Window chrome**: switch between Standard and Elegant window controls.
- **Studio defaults**: set the starting body, background, template fill, and template background colors.

Palette and color-scheme changes preview immediately. Use **Save changes** to keep them; leaving Settings without saving restores the previous appearance.

## Watermark

Configure the text, typeface, size, color, opacity, position, and rotation applied to captured previews. The page includes a live preview of the saved watermark configuration.

## About

About shows the installed version, software-update status, and release notes. When a release is available, Cortex Studio downloads it in the background and shows progress in the main toolbar; once ready, choose **Restart to update** to install it and reopen the app. Experimental features and diagnostics now live in the advanced area at the bottom of About instead of a separate Settings destination.

If something behaves strangely after enabling experimental features, disable them and restart Cortex Studio.

## Feedback

Use **Send feedback** in the top bar to submit a structured bug report or feature request without leaving Cortex Studio. Bug reports can optionally include recent console logs; app version and device context are added automatically.

## Persistence

Settings are saved locally (no cloud, no accounts).

`Ground Shadows` is a global viewer default. It applies immediately to open Studio viewer tabs, including multi-compare mode, and is not stored per workspace.
