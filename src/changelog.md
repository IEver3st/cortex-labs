# Cortex Studio 4.1 — PRISM

> PRISM expands one focused Studio workflow across personal appearances, vehicle liveries, EUP clothing, and format-aware template output.

## New

- Studio Appearance Presets | Choose from 12 full-workbench palettes with instant preview and independent System, Light, and Dark color schemes.
- Automatic EUP Templates | Generate templates from `.ydd` clothing models with EUP-aware UV behavior and separate output for multi-drawable dictionaries.
- In-App Feature Requests | Send structured feature requests with focused prompts and request-specific GitHub labels.

## Improved

- Template Generator Workbench | Work from a compact inspector and dominant canvas with Model, Template, and Split views plus contextual marker tools.
- First-Run Setup | Start from one focused destination choice, launch Home first, and customize preferences only when needed.
- Settings Workspace | Find appearance, workflow, and advanced controls in tighter task-based groups.
- Viewer Controls | Use workflow-specific controls for Livery, All Textures, EUP, and Multi without repeated summaries or decorative steps.
- Scene Lighting | Position lighting by dragging, keyboard adjustment, precision sliders, or quick presets.
- Format-Aware Templates | Preserve each model's real YFT or YDD source type and apply the appropriate UV, material, and mesh policy.

## Fixed

- Active Tab Seam | Active tabs remain visually connected to their workspace while opening and switching tabs.
- Theme-Aware Controls | Buttons, toggles, focus states, and workbench accents consistently follow the selected Studio palette.
